# 🏙️ Smart City Clean (RAD & SDD)

Comprehensive Object-Oriented Analysis & Design (OOAD) and UML documentation for an advanced IoT-based waste management system.

## 📌 Project Overview
This project focuses on the rigorous system analysis and architectural design phases of a smart waste collection infrastructure. It outlines system requirements, behavioral scenarios, and structural components using standardized UML modeling.

## 📄 Documentation Included
- **Requirements Analysis Document (RAD):** System scope, actors, detailed use-case scenarios, and functional/non-functional requirements.
- **System Design Document (SDD):** Architectural blueprints, subsystem decomposition, sequence diagrams, and class models.
- **UI & Architectural Mock-ups:** Visual interface prototypes and workflow diagrams.

## 👥 Team & Collaboration
Co-developed as a 6-member team project focusing on enterprise IoT software engineering practices.

## 💻 Tech Stack & Tools
- **Modeling & Design:** UML, Object-Oriented Analysis & Design (OOAD)
- **Documentation:** System Architecture Blueprints, Use-Case & Sequence Diagrams
